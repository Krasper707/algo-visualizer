# Advanced Sorting Visualizer

A powerful web-based tool to visualize various sorting algorithms. This updated version features a complete playback engine, allowing you to pause, play, step forward, and step backward through the sorting execution frames.

## Features

- **Step-by-Step Playback**: Play, Pause, Next Step, Previous Step, and Reset.
- **Multiple Algorithms**: Bubble, Selection, Insertion, Merge, Quick, Heap, Shell, Cocktail Shaker.
- **Live Statistics**: Tracks the exact number of array comparisons and swaps/overwrites.
- **Algorithm Info**: Displays Time and Space complexity for the selected algorithm.
- **Custom & Massive Datasets**: Input custom comma-separated values or generate arrays up to 150+ items instantly.
- **Dynamic Sizing & Color Coding**: Highlights compared items (yellow), swapped items (red), and sorted items (green).

## How to Run & Deploy

1. Ensure `index.html`, `style.css`, and `script.js` are in the same directory.
2. Open `index.html` in your browser.
3. **To Deploy on Vercel**:
   - Drag and drop the folder into the Vercel dashboard.
   - OR push to a GitHub repository and link it to Vercel (No build commands needed).
